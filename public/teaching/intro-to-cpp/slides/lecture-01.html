Why C++?

  • Compiled to machine code: fast, predictable performance
  • Direct control over memory and hardware
  • Used in games, trading systems, browsers, embedded and robotics
  • Strongly typed: many mistakes are caught before the program runs

From source to program

  1. Preprocess: handle #include
  2. Compile: C++ → object code
  3. Link: combine objects and libraries
  4. Run: the OS loads the executable
g++ -std=c++17 -Wall hello.cpp -o hello
./hello

-Wall turns on helpful warnings. Always use it.

Hello, world


      #include <iostream>

      int main() {
          std::cout << "Hello, world!" << std::endl;
          return 0;
      }
    
Hello, world!

Anatomy of a program


        #include <iostream>   // 1

        int main() {            // 2
            std::cout           // 3
                << "Hi\n";      // 4
            return 0;           // 5
        }
  1. Pull in the I/O library
  2. Execution starts at main
  3. std::cout is the output stream
  4. << sends data to the stream
  5. Return code 0 means success

Reading input


      #include <iostream>
      #include <string>

      int main() {
          std::string name;
          int age;
          std::cout << "Name and age? ";
          std::cin >> name >> age;
          std::cout << name << " will be " << age + 1 << " next year\n";
      }
    
Name and age? Asha 20
Asha will be 21 next year

Watch out


      int x;                  // uninitialized!
      std::cout << x;         // undefined behavior

      int y = 7 / 2;          // 3, integer division
      double z = 7 / 2.0;     // 3.5
Always initialize your variables.
