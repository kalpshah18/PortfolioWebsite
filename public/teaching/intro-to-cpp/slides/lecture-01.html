COMPILER TRICK 2

Constant folding

int week = 60 * 60 * 24 * 7;

int week = 604800;

Worked out once, before the program even runs

What about this?

Can the compiler work out a × b × c in advance?

cin >> a >> b >> c;

cout << a * b * c;

No: a, b and c are only known when the program runs.

If they were fixed values written in the code, then yes, it could fold them.
